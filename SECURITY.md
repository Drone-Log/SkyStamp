# Security policy

## Supported versions

Only the latest release receives fixes. Please update before reporting.

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Report it privately via [GitHub → Security → Report a vulnerability](https://github.com/Drone-Log/SkyStamp/security/advisories/new).
Include what you found, how to reproduce it, and what impact you think it has.

You'll get a reply within a few days. Once a fix is released, the issue is disclosed in a security advisory,
with credit to you unless you prefer otherwise.

SkyStamp runs entirely on your computer: it reads your video and SRT files locally and only connects to the
internet to download map tiles (OpenStreetMap / Esri) for the mini-map.
